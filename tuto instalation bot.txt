TUTO COMPLET BOT DISCORD ↔ WHATSAPP (AVEC WEBHOOK)

============================================================

1. PRÉREQUIS
   ============================================================

Tu dois avoir :

* Un PC sous Linux (Ubuntu recommandé)
* Un compte Discord
* Un compte WhatsApp
* Internet

============================================================
2) INSTALLER NODE.JS (LINUX)
============================

Ouvre un terminal et tape :

sudo apt update
sudo apt install nodejs npm -y

Vérifie l’installation :

node -v
npm -v

Si ça affiche une version → OK

============================================================
3) CRÉER LE DOSSIER DU BOT
==========================

mkdir bot-wa-discord
cd bot-wa-discord

============================================================
4) INSTALLER LES MODULES
========================

npm init -y

Puis :

npm install discord.js whatsapp-web.js qrcode node-fetch fs

============================================================
5) CRÉER LES DOSSIERS NÉCESSAIRES
=================================

mkdir media
mkdir pp

============================================================
6) CRÉER LE FICHIER DU BOT
==========================

nano index.js

Colle dedans TON SCRIPT COMPLET

Puis :

CTRL + X
Y
Entrée

============================================================
7) CRÉER LE BOT DISCORD
=======================

1. Va sur : https://discord.com/developers/applications

2. Clique sur "New Application"

3. Va dans "Bot"

4. Clique sur "Add Bot"

5. Active :

   * MESSAGE CONTENT INTENT

6. Copie le TOKEN

7. Invite le bot :
   OAuth2 → URL Generator :

   * bot
   * permissions :
     → Send Messages
     → Read Messages

============================================================
8) RÉCUPÉRER L’ID DU SALON
==========================

Dans Discord :

Paramètres → Avancé → activer "Mode développeur"

Puis clic droit sur ton salon → "Copier l’ID"

============================================================
9) CRÉER LE WEBHOOK
===================

Dans ton salon Discord :

Paramètres du salon → Intégrations → Webhooks

Créer un webhook
Copier l’URL

============================================================
10) CONFIGURER LE SCRIPT
========================

Dans ton fichier index.js remplace :

* DISCORD_TOKEN
* DISCORD_CHANNEL_ID
* WEBHOOK_URL

Optionnel :

* bannedWords
* userProfiles (photos dans ./pp)

============================================================
11) LANCER LE BOT
=================

node index.js

============================================================
12) CONNECTER WHATSAPP
======================

Un QR code va apparaître sur Discord

Sur ton téléphone :

WhatsApp → Appareils liés → Lier un appareil

Scanne le QR code

============================================================
13) UTILISATION
===============

COMMANDES DISCORD :

!groupes
→ Liste les groupes WhatsApp

!select 1
→ Sélectionne le groupe

Ensuite :

* Tout message Discord → WhatsApp
* Tout message WhatsApp → Discord

============================================================
14) FONCTIONNALITÉS
===================

✔ Messages texte bidirectionnels
✔ Images / vidéos / fichiers
✔ Photos de profil via webhook
✔ Système de réponse (reply)
✔ Logs dans latest.log
✔ Filtre de mots

============================================================
15) ERREURS COURANTES
=====================

BOT NE SE CONNECTE PAS :
→ Vérifie le TOKEN

QR NE S’AFFICHE PAS :
→ Vérifie l’ID du salon

WHATSAPP NE RÉPOND PAS :
→ Vérifie que tu as sélectionné un groupe (!select)

WEBHOOK NE MARCHE PAS :
→ Vérifie l’URL

============================================================
16) LANCEMENT AUTOMATIQUE (OPTIONNEL)
=====================================

Installer pm2 :

npm install -g pm2

Lancer le bot :

pm2 start index.js

Auto start :

pm2 startup
pm2 save
