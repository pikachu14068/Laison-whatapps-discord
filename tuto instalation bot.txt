TUTO INSTALLATION BOT WHATSAPP ↔ DISCORD (UBUNTU)

==================================================
1. INSTALLER NODE.JS
==================================================

Vérifie si Node est installé :
node -v

Si pas installé :

sudo apt update
sudo apt install -y curl
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

Vérifie :
node -v
npm -v


==================================================
2. CRÉER LE PROJET
==================================================

mkdir bot-wa-discord
cd bot-wa-discord


==================================================
3. INSTALLER LES MODULES
==================================================

npm init -y
npm install discord.js whatsapp-web.js qrcode node-fetch


==================================================
4. CRÉER LES DOSSIERS
==================================================

mkdir media
mkdir pp


==================================================
5. AJOUTER LE SCRIPT
==================================================

nano index.js

Colle ton script dedans

Puis :
CTRL + X
Y
ENTER


==================================================
6. CONFIGURER LE SCRIPT
==================================================

Dans index.js :

const DISCORD_TOKEN = "TON_TOKEN";
const DISCORD_CHANNEL_ID = "ID_DU_SALON";
const WEBHOOK_URL = "TON_WEBHOOK";


==================================================
7. CRÉER LE BOT DISCORD
==================================================

1. Aller sur :
https://discord.com/developers/applications

2. Cliquer :
New Application

3. Onglet Bot → Add Bot

4. Copier le TOKEN

5. Activer :
- MESSAGE CONTENT INTENT


==================================================
8. INVITER LE BOT
==================================================

OAuth2 → URL Generator

Scopes :
- bot

Permissions :
- Send Messages
- Attach Files
- Read Messages

Ouvrir le lien et inviter le bot


==================================================
9. CRÉER UN WEBHOOK
==================================================

1. Aller dans ton salon Discord
2. Paramètres → Intégrations → Webhooks
3. Créer webhook
4. Copier l’URL

Mettre dans le script :
const WEBHOOK_URL = "ICI"


==================================================
10. RÉCUPÉRER L’ID DU SALON
==================================================

1. Paramètres Discord → Avancé
2. Activer mode développeur
3. Clic droit salon → Copier l’ID


==================================================
11. LANCER LE BOT
==================================================

node index.js


==================================================
12. CONNECTER WHATSAPP
==================================================

Le bot envoie un QR code sur Discord

Sur téléphone :
WhatsApp → Appareils liés → Ajouter un appareil

Scanner le QR


==================================================
13. TEST
==================================================

Envoyer message WhatsApp → Discord

Envoyer message Discord → WhatsApp


==================================================
14. AJOUTER DES PHOTOS DE PROFIL
==================================================

Mettre images dans le dossier :

./pp/

Exemple :

./pp/user1.png
./pp/user2.png

Dans le script :

const userProfiles = {
  "33600000001@c.us": "./pp/user1.png"
};


==================================================
15. PROBLÈMES COURANTS
==================================================

QR code ne s’affiche pas :
- Vérifier ID du salon
- Vérifier permissions du bot

Bot ne répond pas :
- Vérifier token
- Relancer node index.js

WhatsApp bug :
rm -rf .wwebjs_auth

Puis relancer


==================================================
16. BONUS (OPTIONNEL)
==================================================

Installer PM2 :

npm install -g pm2

Lancer le bot en continu :

pm2 start index.js
pm2 save
pm2 startup


==================================================
FIN DU TUTO
==================================================
